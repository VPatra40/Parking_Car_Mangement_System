# Parking_Car_Mangement_System
A simple REST API application to manage vehicle entries and exits in a parking lot. It allows users to record entry and exit times, driver name, vehicle details, and view parking history. Data is stored and retrieved from a MySQL database using JPA. Validated through SQL queries and terminal testing.
